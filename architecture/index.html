An evidence-to-forecast compiler

One reusable forecasting worker, run four times in parallel — one per company. Bounded Tavily research freezes admissible web evidence alongside the supplied corpus; deterministic gates then decide what may enter the source-backed profile, signal map and auditable forecast.

The rule that keeps it honest. The model may propose structured observations. It may not invent sources, choose arbitrary weights, perform forecast arithmetic, or write submission values. A signal moves a number only when its evidence and declared transformation pass deterministic validation.

How the work fans out

One worker, four companies, in parallel

An orchestrator spins up an isolated worker per company. Tavily search and extraction run concurrently, while provenance, cutoff and look-ahead gates fail closed before exactly three forecasts can be returned.

The worker

Every worker follows six stages

Profile the company, decide which signals matter, resolve them into cited evidence, combine them into an auditable number, stress the scenarios, then challenge and validate before returning.

Signals & roles

Not every signal gets a number

Instead of inventing arbitrary weights, each signal is assigned a role. A weight appears only when a backtest or historical analysis defensibly justifies it.

constraint

Enforced

Accounting identities the forecast must satisfy — never weighted.

e.g. EPS must reconcile with profit, tax and diluted shares.

anchor

Starting range

A direct, defensible estimate that forms the forecast's starting point.

e.g. Management's stated Q3 revenue guidance range.

driver

Moves the number

A quantified effect applied through an explicit formula.

e.g. revenue × volume change × price/mix change.

modifier

Guides judgement

Qualitative evidence that selects the upper or lower half — never given false precision.

e.g. "automotive demand stronger than expected."

scenario trigger

Conditional risk

A risk that only matters if an event occurs — lives in a scenario, not the base.

e.g. a proposed tariff taking effect before period close.

Every number keeps its receipt

No value reaches a forecast without an unbroken chain from a hashed source to an explicit formula. Accepted inputs replay to the same output.

Disciplined scope

What's in, and what's deliberately out

The architecture stays generic even though only the signals needed for today's four companies are built.

✓ Implemented now

  • ✓ Strict JSON company profiles and signal maps
  • ✓ Bounded Tavily search/extract across four concurrent company lanes
  • ✓ Immutable source snapshots, audit manifests and cutoff enforcement
  • ✓ Independent no-web look-ahead review and fail-closed v2 handoff
  • ✓ Source hashes, URLs, exact quotations and cutoff checks
  • ✓ Reusable management-guidance and explicit-driver resolvers
  • ✓ Deterministic anchor-plus-driver combination in Decimal
  • ✓ Qualitative modifiers and conditional scenarios, no arbitrary weights
  • ✓ Challenge checks for unsupported evidence, mismatches, double-counting
  • ✓ Replayable JSON run receipts + an end-to-end ADI example
